## 챕터 5: DFS/BFS
### DFS/BFS 이해에 필요한 사전 개념 정리
* 오버플로: 특정한 자료 구조가 수용할 수 있는 데이터 크기를 이미 가득 찬 상태에서 삽입 연산을 수행할 때 발생  
* 언더플로: 특정한 자료 구조에 데이터가 전혀 없는 상태에서 삭제 연산 수행 시 발생   

### 스택
* 박스 쌓기와 유사
* 선입 후출 혹은 후입 선출 구조 
* 파이썬에서 별도의 라이브러리 없이 이용 가능: apend, pop 메쏘드로 푸시, 팝 수행

### 큐
* 줄 서기와 유사
* 선입선출 구조
* from collections import deque 모듈 이용하여 사용 가능: append, popleft 메쏘드 이용 

### 재귀 함수
* 반복문보다 코드를 간결하게 구현 가능하다는 이점 존재. 

### 그래프
* 노드(Node)와 간선(Edge)로 표현되는 구조
* 인접 행렬, 인접 리스트 형태로 표현 가능. 

### DFS (Depth First Search)
* 깊이 우선 탐색: 그래프에서 깊은 부분을 우선적으로 탐색하는 알고리즘
* 스택 구조에 기반함.
* O(N)의 시간 소요 
* [추천 문제 백준 링크](https://coding-grandpa.tistory.com/122)
    * 1260 
    * 2606
    * 1012
    * 2667 
* 팁: 파이썬 기본 재귀 함수 깊이 상한= 1000 이라 recursion error 발생 가능. 따라서 아래 코드를 이용해 제한 푸는 것 필요
```
sys.setrecursionlimit(10000)
```

### BFS (Breadth First Search)
* 너비 우선 탐색: 가까운 노드부터 탐색하는 알고리즘 
* 큐 구조에 기반함. 
* O(N)의 시간 소요. 일반적으로 **수행 시간이 DFS보다 짧은 편**  (코딩 테스트 한정)
* [추천 문제 백준 링크](https://www.acmicpc.net/workbook/view/18658)
* 정답률 높은 문제 5개를 풀며 연습하기 

## 챕터 6: 정렬 
### 선택 정렬 (Selection Sort)
* 가장 원시적인 정렬 알고리즘
* 가장 작은 데이터 <-> 맨 앞 데이터, 그다음 작은 데이터 <->두 번째 데이터 위치, ... 
* 시간 복잡도: O(N^2^)
* 퀵정렬, 파이썬 기본 정렬 라이브러리가 훨씬 수행시간이 짧은 편 

### 삽입 정렬 
* 특정한 데이터를 적절한 위치에 삽입하며 정렬
* 선택 정렬은 스왑한는 것이라면, 삽입 정렬은 데이터와 데이터 사이에 특정 데이터를 삽입하며 정렬
* 두 번째 요소부터 조작. 
* 시간 복잡도: O(N^2^)
    * 이미 행렬이 많이 정렬된 상태라면 O(N)도 가능 -> 이런 경우 퀵정렬보다 유리할 수도 있음 

### 퀵정렬
* 기준(피벗) 설정 후 큰 수와 작은 수의 위치를 교환 후 리스트를 반으로 나누는 방식으로 동작
* 시간 복잡도: O(NlogN). 단, 최악의 경우 O(N^2^)도 가능

### 계수정렬 
* 특정 조건 하에서 빠르게 동작하는 정렬 알고리즘
    * 모든 데이터가 양의 정수
    * 데이터 갯수 = N, 최댓값 = k -> 수행시간: O(N + K) 
    * 가장 큰 데이터 - 가장 작은 데이터 <= 1,000,000
* 기본 원리: 가장 작은 데이터~가장 큰 데이터를 1단위로 갖는 새로운 행렬 생성-> 원본 행렬에 들은 각 원소의 수를 카운트하여 새로운 행렬에 저장 -> 새로운 행렬에서 값이 0인 원소를 제외한 나머지 원소의 인덱스값을 리턴 
* 시간 복잡도: O(N + K)
* 공간 복잡도: O(N + K)로 입력 데이터 상태에 따라 과하게 복잡할 수도 있음. 그러나 코딩테스트 시스템 환경 문제 때문에 데이터 개수는 1,000만 개 미만일 것으로 예상. 

### 파이썬의 기본 정렬 라이브러리
* sorted()
    * 병합 정렬 기반
    * 시간 복잡도: O(Nlog N) (최악의 상황에서도 보장)
    * 리스트, 딕셔너리 자료형 등을 정렬 가능 
    * key 매개변수: 함수 혹은 람다 함수
* sort()
    * 리스트 객체의 내장 함수
    * 리스트 변수가 하나 있을 때 내부 원소 바로 정렬 가능 
    * key 매개변수: 함수 혹은 람다 함수
